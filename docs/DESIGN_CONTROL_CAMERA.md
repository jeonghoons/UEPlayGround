# DESIGN_CONTROL_CAMERA

## 확정 사항
- 검은사막식 조작/카메라를 참고한다 (모작 아님).
- 입력은 Enhanced Input을 사용한다.
- 이동 입력은 **WASD뿐**이다. 달리기 전용 키(Shift 등)를 따로 지정하지 않는다. 점프, 대시, 커서 모드, 줌 등은 이후 단계에서 추가한다.
- 카메라는 **검은사막식 마우스 회전**을 1차부터 구현한다.
- 이동은 **자동 달리기**다. 걷기/달리기 전환 키가 없고, 입력 크기/가속에 따라 속도가 올라가며 UE 매니퀸 템플릿과 비슷하게 **블렌드 스페이스**(속도 기반)로 Idle → Walk → Run을 자동 블렌딩한다.
- WASD는 카메라 기준 이동, 마우스 이동으로 카메라가 캐릭터를 중심으로 회전한다 (검은사막식).
- 이동/카메라 수치(최대 속도, 가속도, 감도 등)는 MovementTable에서 읽는다.
- 스킬은 숫자키 1~5 (`DESIGN_COMBAT.md`, Phase 4).

## 미정 (필요한 Phase에서 확정)

- 템플릿의 `Do*` BlueprintCallable 패턴을 따를지 (DECISIONS.md에 기록)
