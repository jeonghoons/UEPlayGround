# DESIGN_COMBAT

## 확정 사항
- 스킬의 쿨타임, 시전시간, 판정 방식은 SkillTable 데이터로 정의한다.
- 판정 방식: 부채꼴(Sector), 직선(Line), 프로젝타일(Projectile).
- **콤보 공격은 없다.** 기본 공격은 단일 동작이며 연계 입력 윈도우를 두지 않는다.
- **스킬은 숫자키 1~5로 발동**하고, 사용 가능한 스킬 목록은 **무기별**로 정해진다 (WeaponTable → 스킬 ID 목록).
- 검은사막식 커맨드 요소(방향/조합 입력)는 필요할 때 SkillTable의 입력 정의로 확장한다. 1차 구현은 숫자키만.
- 맨손 상태는 공격/스킬 불가 (스킬 목록이 비어 있고 공격 불가 플래그 — `DESIGN_ANIMATION.md` 참고).
- 판정 타이밍은 C++ 타이머가 아니라 AnimNotify가 소유 캐릭터를 콜백한다.
- 판정 경계: **클라이언트가 AnimNotify 시점에 Sector/Line/Projectile 판정을 수행하고, 맞은 대상 목록을 백엔드(`IGameBackend`)에 보고**한다. 데미지 계산과 사망 결정은 백엔드(지금은 `ULocalGameBackend`, 나중에 서버)가 한다.
- 서버 연동 전에는 몬스터 AI를 만들지 않는다 (`DESIGN_ARCHITECTURE.md` 참고).
- 판정 방식과 UI는 검은사막/붉은사막을 참고하되 모작은 하지 않는다.

## 초안 구조
- `SkillComponent`: 쿨타임/시전 상태, 숫자키 슬롯 ↔ 현재 무기 스킬 목록 매핑
- 판정 모듈: Shape별로 분리, 디버그 드로잉 지원
